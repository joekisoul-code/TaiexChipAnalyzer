# 台股大盤籌碼即時分析 (TAIEX Chip Analyzer)

整合 **八大行庫、三大法人 (外資/投信/自營商)、融資融券、借券賣出、外資台指期未平倉、選擇權 P/C 比、大額交易人、量價與趨勢**，
每日計算「綜合籌碼分」與「是否可進場」判讀，並提供個股籌碼分析。資料以官方開放資料為主，
玩股網 (`wantgoo.com/stock/margin-trading/market-price/taiex`) 與嗨投資為輔。

## 安裝

```bash
pip install -r requirements.txt
python -m playwright install chromium     # 選用：抓玩股網 (大盤融資維持率、各行庫明細、借券歷史)
```

環境變數 (皆選填)：

| 變數 | 說明 |
|---|---|
| `FINMIND_TOKEN` | FinMind token。免費註冊可提高流量；贊助等級才有券商分點 / 八大行庫個股 API |
| `CHIP_WANTGOO=0` | 停用玩股網 (Playwright) |
| `CHIP_DATA_DIR` | 快取與 SQLite 位置 (預設 `./data`) |

## 平板 App 無伺服器版 (GitHub Pages + GitHub Actions)

原理：**你不需要開電腦、也不需要自己的伺服器**。GitHub Actions (免費) 依排程在雲端執行本專案的計算，把結果輸出成靜態 JSON
連同 PWA 頁面發布到 GitHub Pages；平板只是打開一個網頁 (加入主畫面後就是 App)。瀏覽器無法直接抓證交所即時報價
(只有 TWSE rwd 與 FinMind 允許跨域)，所以即時資料由排程每 5 分鐘更新一次，延遲約 5~8 分鐘。

**目前已部署**：repo https://github.com/joekisoul-code/TaiexChipAnalyzer ，平板網址 **https://joekisoul-code.github.io/TaiexChipAnalyzer/**
(第一次完整計算在 Actions 上約 7.5 分鐘；盤中 fast 模式約 1~2 分鐘)。

**一次性設定 (約 10 分鐘，已完成，留作參考)**
1. 到 GitHub 建立一個 repository (可以 Private)，把本資料夾推上去：
   ```bash
   cd D:\TaiexChipAnalyzer
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<repo>.git
   git push -u origin main
   ```
2. Repo → Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 **gh-pages** / (root)。
3. Repo → Settings → Actions → General → Workflow permissions 勾 **Read and write permissions**。
4. (選填) Settings → Secrets and variables → Actions：Secret `FINMIND_TOKEN`；Variable `CHIP_WATCHLIST`（例如 `2330,00631L,00685L,00981A,00988A`）。
5. Actions 頁面 → publish-app → **Run workflow** (mode=train) 跑第一次 (約 15 分鐘，含模型訓練)；之後排程自動執行。
6. 平板開 `https://<你的帳號>.github.io/<repo>/`，Safari「加入主畫面」/ Chrome「安裝應用程式」。

排程 (台北時間)：盤中 09:00~13:59 每 5 分鐘快照；15:40、21:45 盤後完整重算 (含玩股網 Playwright)；週日 06:00 重訓模型與長歷史回測。
Private repo 的 GitHub Pages 需要 GitHub Pro；免費帳號請用 Public repo (程式碼公開，資料無隱私問題)。
Actions 免費額度每月 2,000 分鐘 (Public repo 不計)，本排程每月約 1,500 分鐘，若用 Private repo 可把盤中 cron 改成每 10 分鐘。

本機預覽靜態版：`python tools/export_static.py` 後 `python -m http.server 8700 --directory site`。

## 即時追蹤 (`chip/realtime.py`)

盤中每 5 秒可更新的「盤勢」層，補足籌碼資料盤後才公布的空窗：

| 即時資料 | 來源 | 用途 |
|---|---|---|
| 加權指數 1 分鐘分時、累積成交量/金額 | TWSE MIS `mis_ohlc_TSE.txt` | 分時圖、**量能進度推估** (依已開盤分鐘數換算全日 vs 20 日均) |
| 加權/櫃買即時報價 | TWSE MIS `getStockInfo.jsp` | 漲跌、盤中相對 MA5/MA20 位置 |
| 40 檔權值股即時報價 (含五檔委買賣量) | TWSE MIS (一次請求) | **市場廣度** (漲跌家數)、**委買/委賣比**、台積電與大盤背離 |
| 臺指期日盤/夜盤即時報價、未平倉、現貨參考價 | TAIFEX MIS `getQuoteList` | **期現價差** (正/逆價差)、**夜盤漲跌** (隔日開盤參考) |

- **盤勢即時分** (-100~100)：指數漲跌、期現價差、廣度、委買賣比、量能 (方向 × 倍數)、均線位置、台積電相對。
- **籌碼 × 盤勢交叉解讀**：例如「籌碼偏多但盤勢弱 → 多頭拉回不急停損」「籌碼偏空但盤勢強 → 反彈不追高」。
- **警示引擎** (`ALERT_RULES`，同日同規則只觸發一次)：跌破/站回月線、漲跌逾 2%、逆價差/正價差逾 0.4%、量能 1.5x 且下跌/上漲、
  權值股普跌/普漲 (≥80%)、委賣過重、台積電背離、夜盤波動逾 1%、乖離過大。
- **推播** (`chip/notify.py`)：console + `data/alerts.log`；設 `CHIP_WEBHOOK_URL` (Discord/Slack) 或 `CHIP_TELEGRAM_TOKEN`+`CHIP_TELEGRAM_CHAT` 可推到手機。
- **盤中時間序列**：每次快照寫入 SQLite `intraday` 表，儀表板畫出當日盤勢分與期現價差走勢。

```bash
python cli.py rt          # 印一次即時快照
python cli.py watch 30    # 每 30 秒監看 + 警示推播 (籌碼資料每 30 分鐘重算)
```

## 評分模型 v2 (`chip/analysis/market.py`)

**市場狀態機**：依月線/季線結構判定 多頭 (價>季線且月線>季線)、空頭 (價<季線且月線<季線)、盤整，
三種狀態使用不同權重 (`STATE_WEIGHTS`)：多頭加重趨勢、量價、融資過熱；空頭加重外資期貨、官股護盤、維持率、避險情緒。

每個因子給 -2 ~ +2 分，乘上狀態權重加總後正規化成 -100 ~ +100 的「綜合籌碼分」，再取 3 日 EMA 平滑作為決策依據：

| 因子 | 基本權重 | 規則摘要 |
|---|---|---|
| 外資現貨買賣超 | 3.0 | 當日與 5 日累計 60 日 z；單日極端賣超 (z<−2.2) 且重挫 → +0.5 賣壓高潮修正；極端買超且乖離大 → −0.5 |
| 投信買賣超 | 1.5 | 5 日累計 z |
| 自營商 | 0.5 | 當日 z (多為避險，權重低) |
| 外資台指期部位 | 2.5 | 淨部位一年百分位 50% + 日變化 z 30% + **現貨/期貨一致性** 20% (現貨買+期貨加多 = 多方一致) |
| 八大行庫 | 1.5 | 5 日累計 z；指數跌且**連續買超 ≥3 日** → 至少 +1.5 (護盤)；漲且連賣 ≥3 日 → 至多 −1 (調節) |
| 融資量價象限 | 2.0 | 融資 20 日變化 × 指數 20 日變化：跌而融資增 (接刀) −2；融資增速>指數+4% (追價) −2；斷頭清洗 0/止穩 +1；漲而融資減 (沉澱) +2 |
| 融資維持率 | 1.5 | ≥170 +1 / 160–170 0 / 150–160 −1 / <150 −2 |
| 融券 | 1.0 | 上漲中融券增加 = 軋空 (+)；下跌中融券增加 = 空方壓力 (−) |
| 借券賣出餘額 | 1.0 | 5 日變化 z 取反 |
| P/C 比 (OI) | 1.0 | ≥120 +2 / ≥110 +1 / ≤90 −1 / ≤80 −2 |
| 大額交易人 (特定法人) | 1.0 | 前十大淨部位 / 市場 OI |
| 量價 | 1.5 | 價漲量增 +1.5、價跌量增 −1.5、爆量長黑 −2、**量縮整理 (5 日量 <0.8x 且在月線上)** +0.5 |
| 趨勢 | 2.0 | 均線結構 + **月線 5 日斜率** ±0.5 + **20 日新高/新低** ±0.5 + 乖離修正 |

判讀輸出：
- **信心度** 高/中/低：因子方向一致比例 × 資料完整度；信心低時進場建議自動附註「部位減半」。
- **轉折偵測**：平滑分自 −15 以下回升 / +15 以上回落。
- **主要多空理由**：貢獻最大的前三個因子。
- **進場建議依市場狀態**：多頭 → 順勢進場 / 拉回布局 / 減碼；空頭 → 反轉確認 (站回月線 + 分數≥25) / 末端試單 (≥3 底部訊號且動能回升) / 不進場；盤整 → 區間規則。
- **盤中即時提示** (`intraday_hint`)：以現價推估月線/5 日線位置與乖離，提醒「盤中站回/跌破月線」「重挫勿接刀」。籌碼資料盤中仍為前一日。

個股模型 (`stock.py`) 新增：相對大盤強弱 (20 日)、外資投信雙買/雙賣、融資四象限、依大盤狀態的進場規則。

權重與門檻集中在 `WEIGHTS` / `STATE_WEIGHTS` / `score_frame()`，可自行調整。

## 長歷史優化 v3 (`chip/analysis/backtest.py`，`python cli.py optimize`)

以 FinMind 免費資料回溯 2010-01 ~ 2026-09 (4,092 個交易日；期貨法人自 2018-06)，用同一套因子計算，
檢驗每個因子與未來 5/10/20 日報酬的排序相關 (IC)、逐年一致性、市場狀態拆解、事件研究與逐年樣本外。主要發現與對應修改：

| 發現 (2010~2026) | 修改 |
|---|---|
| 外資台指期部位 (含現貨一致性) 是唯一逐年皆正的因子 (2018~2026 每年 IC>0，年均 0.16) | 權重 2.5 → 3.5，空頭狀態 4.0 |
| 外資現貨買賣超 IC≈0；**外資連買 ≥5 日後 10 日報酬顯著落後** (n=449, t=−5.4) | 權重 3.0 → 1.5；連買 ≥5 日扣 0.5 |
| 指數趨勢在 10~20 日視野逐年偏負 (73% 年份 IC<0，年均 −0.11)，台股中期有均值回歸 | 權重 2.0 → 1.0，多頭狀態 0.75 |
| 月線負乖離 <−6% 後 10 日 +3.5%、勝率 75% (t=4.1) | 新增「超跌回歸」單邊因子 (權重 1.5，空頭 2.0) |
| 月線正乖離 >+6% 後 10 日仍 +2.0%、勝率 69% (t=3.3)，動能延續 | 趨勢因子不再因正乖離扣分；高檔風險改 >8% 僅提示 |
| 融資「斷頭清洗」後 10 日 +1.5%、勝率 66% (t=3.9)，最強籌碼訊號 | 象限分 0/+1 → +1.5/+2，列入底部訊號 |
| 融資追價過熱、散戶接刀、籌碼沉澱對未來報酬幾乎無影響 | −2/−2/+2 → −1/−1/+1，權重 2.0 → 1.5 |
| 「量縮整理 (月線上)」後 10 日 −2.1%、勝率 32% (n=34, t=−3.2) | +0.5 → −0.5 |
| 外資期貨空單一年最極端 10% 後並無反彈優勢 | 從底部訊號移除 |
| 空頭狀態 + 平滑分 ≥25 + 站回月線：10 日勝率 74% | 保留為空頭反轉進場規則 |

結果：整體綜合分 IC 由 −0.022 → +0.020，正 IC 年份比 33% → 67%；逐年樣本外 (2015~2026) 平均 IC 由 −0.021 → +0.080，
12 年中 10 年為正 (2015、2017、2018 例外)。`optimize` 另依跨年一致性產生保守的權重倍數 (×0.5 / ×0.75 / ×1 / ×1.25)
寫入 `data/tuned_weights.json`，模型自動套用 (`CHIP_USE_TUNED=0` 停用)。

沒有長歷史的因子 (八大行庫、維持率、借券、PCR、大額交易人) 無法在此驗證，權重維持預設；需程式每日執行累積後再評估。

## 機器學習走勢預測 (`chip/predict/`，`python cli.py train` / `forecast`)

以全部有長歷史的籌碼、價量、狀態、因子分與時間特徵 (星期、距期貨結算日、距月底/季底) 共 50 個特徵，
用 2010~ 資料訓練，2014~2026 逐年 walk-forward 驗證 (測試年前剔除與標籤重疊的日子)。

**實驗結論 (誠實版)**
- 漲跌方向分類 (LightGBM 分類器、邏輯迴歸、不同特徵集) 全部輸給「永遠看漲」基準：準確率 52~57% < 基準上漲率 58~62%，AUC 0.42~0.52。
  台股大盤 5~20 日的方向在這些資料下幾乎不可預測。
- 淺層 LightGBM (葉數 4、min_child_samples 200、強正則) 五種子平均的「期望報酬排序」有微弱但跨年穩定的優勢：

| 視野 | 樣本外 rank-IC (加入國際/跨市場特徵後) | 逐年 IC 平均 | 正 IC 年份 | 加入前 |
|---|---|---|---|---|
| 1 日 | +0.048 | +0.05 | 10/13 | +0.037 |
| 2 日 | +0.053 | +0.07 | 11/13 | +0.019 |
| 3 日 | +0.041 | +0.06 | 10/13 | +0.015 |
| 5 日 | +0.058 | +0.09 | 10/13 | +0.020 (7/13) |
| 10 日 | +0.090 | +0.11 | 11/13 | +0.070 |
| 20 日 | +0.063 | +0.18 | 11/13 | +0.075 |

**隔天 / 後天 / 第三個交易日** (視野 1/2/3 日，休市日以 TWSE 休市日曆跳過)：

| 視野 | 樣本外 rank-IC | 逐年 IC 平均 | 正 IC 年份 | 備註 |
|---|---|---|---|---|
| 1 日 | +0.04 | +0.05 | 10/13 | 最弱→最強五分位上漲率 53% → 55~58% |
| 2 日 | +0.02 | +0.05 | 10/13 | 微弱 |
| 3 日 | +0.02 | +0.05 | 10/13 | 微弱 |

輸出為「預估收盤水準 = 基準價 × (1 + 同分位歷史平均%)」與 20~80% 區間；盤中則以現價為基準。
短視野的可預測性很低，請把區間看得比點估計重要。

**當日每小時** (`chip/predict/intraday.py`)：用 Yahoo Finance ^TWII 近 2 年小時 K (約 480 個交易日)
在 開盤前 / 09:00 開盤 / 10:00 / 11:00 / 12:00 / 13:00 各時間點建立特徵 (跳空、開盤至今、前收至今、當日區間位置與振幅、近 1 小時、
前晚夜盤台指期、前一日籌碼綜合分/外資期貨百分位/乖離/波動、星期、距結算日)，分別預測「到 10:00 / 11:00 / 12:00 / 13:00 / 13:30 收盤」的報酬，
逐月 walk-forward 驗證後同樣做分位校準。盤中每次更新以 TWSE 1 分鐘分時把現價套到目前時間點重算；開盤前以前收為基準、夜盤為跳空代理。
(TWSE 每 5 秒指數統計 `MI_5MINS_INDEX` 也可當來源，但連續請求會被 428 限流，`twse.index_1min()` 保留供補資料。)

小時模型樣本外結果 (2024-03 ~ 2026-09 逐月，共 30 個月)：

| 起點 → 目標 | rank-IC | 方向命中率 (基準) | 解讀 |
|---|---|---|---|
| 開盤前 → 10:00 / 收盤 | 0.56 / 0.60 | 76% / 74% (60% / 57%) | 幾乎全來自「前晚夜盤台指期」→ 開盤跳空。可預測性高，但那是開盤價已反映的部分 |
| 10:00 → 收盤 | 0.03 | 50% (49%) | 盤中小時級走勢基本不可預測 |
| 11:00 / 12:00 / 13:00 → 收盤 | 0.02 / 0.02 / −0.04 | 51% / 52% / 50% | 同上 |

重要陷阱：加權指數 09:00:05 的第一筆「開盤價」是用大量尚未成交股票的前收計算的失真值，開盤後幾分鐘才反映真實跳空。
若把 09:00 當時間點，模型會「預測」到這個失真值的修正 (IC 0.4+)，看似很準其實不可交易，因此模型不設 09:00 時間點，
即時用 09:05 的價當開盤價。開盤前與盤中的校準表分開建立，避免盤中預測被跳空樣本汙染。

**因此模型的輸出方式**：不用模型自己的機率 (過度自信)，而是把預測值對應到樣本外同分位的「實際上漲率、平均報酬、20~80% 區間」
(經驗校準)，並用 pred_contrib 列出推升/壓抑的特徵。盤中另以現價重算價量特徵，給「若以現價收盤」的推估。
個股模型以 40 檔權值股 2018~ 訓練 (混合面板)、目標為相對大盤的超額報酬，2021~2026 逐年樣本外：
5 日 rank-IC +0.06 (6/6 年為正)、10 日 +0.07 (5/6 年)，預測最強五分位 10 日平均超額 +1.39% vs 最弱 −0.77%；20 日轉弱 (3/6 年)。
籌碼特徵對權值股「相對強弱」在 1~2 週視野有可驗證的預測力，但非權值股屬外推。

## 訊號驗證 (重要)

「🧪 訊號驗證」頁與 `python cli.py backtest` 會計算平滑綜合分與未來 5/10/20 日報酬的關係，並對照全體基準。
v2 以 2025-09 ~ 2026-09 資料 (單邊多頭年) 的結果：偏空 → 中性 → 偏多 分區的未來報酬大致遞增
(10 日：2.1% / 2.7% / 3.6%，偏多分區 20 日勝率 97% vs 全體 81%)，但整體排序相關仍只有 0.05~0.10，
極端分區樣本各僅 5 天，無統計意義。「資料驅動權重參考」用 ridge 迴歸擬合的權重在樣本外反而更差 (過擬合)，
這正是它只能當參考的原因。

結論：本模型是**籌碼狀態的結構化描述**，不是經過驗證的預測系統。請把它當作「誰在買、誰在賣、風險在哪、
現在處於什麼狀態」的整理；PCR / 維持率 / 大額交易人歷史需程式每日執行累積後，驗證才會完整。
