# radar5 (2026-10-07)：潛力股雷達誠實回測

- 問題：模型檔的 170 檔宇宙是 2026-09 依「當時」成交值挑的；拿它回測 2022~ 等於事先知道哪些股票會變大 (後見之明)。
- 做法：`build_panel.py` 抓全上市 Yahoo 10y 日 K；`harness.py` 用正式 `treasure.features` 建特徵，宇宙改為每月第一個交易日依前一交易日為止 120 日平均成交值排名 (時點正確，`rk`)；
  `final_tables.py` 以 PIT 前 170 大訓練 + 選股、逐年走動式、5 種子 × 2 條選股路徑 → `final_constants.json` (寫入 `chip/predict/treasure_live.py` 的 RADAR_BT / RADAR_PATH / RADAR_FAIL / RADAR_TIER / RADAR_DAY0)。
- 結論 (5 項研究 + 各自反方重跑)：A/A+ 勝率 0.695→0.62、飆股 0.553→0.51 (舊數字含後見之明)；重訓頻率、訓練窗、近期加權、候選池大小/門檻/閘門/飆股前 K、lambdarank、截面特徵、種子平均、改目標、模型容量都沒有穩定改善。
  飆股追蹤表改用「仍在追蹤」母體 (舊表含已飆結案 → 後段高估 30~50pt)。
- 限制：價格清單 = 2026-10-02 仍上市的股票 (2888 新光金等已下市者缺)；壞資料濾網 (單日 >11%) 會看到之後 21 天 → 絕對水準仍略樂觀。
- 研究腳本的資料路徑是相對本資料夾 (parquet 不進 git，要先跑 build_panel.py)。
